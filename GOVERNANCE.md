# Governance

This is an open-source reference implementation under the itonami actor pattern
(per ADR-2607011000 / CLAUDE.md, cloud-itonami).

## Decision-Making

Changes to the following require issue discussion and maintainer consensus:

- Governor hard invariants or escalation rules
- Core protocol definitions (Store, Advisor)
- Scope boundaries (administrative vs. clinical)
- Test coverage

Typo fixes, dependency updates, and documentation improvements can be merged
faster with maintainer review.

## Release

Tagged releases follow `v<semver>` and are announced via GitHub releases.
